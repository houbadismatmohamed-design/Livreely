# 🚚 LIVRILY – Delivery & Shop Management

A complete, free, real‑time delivery management system with a client storefront, shop owner dashboard, and driver/manager apps.

## 🔥 Features

- **Multi‑role access**: Client store, Shop owner, Manager, Driver – all from one portal.
- **Real‑time updates**: Orders sync instantly across all apps using Firebase.
- **Order tracking**: Clients can track their order status (pending → accepted → picked → near → delivered).
- **Shop owner dashboard**: Manage products (add/edit/delete), accept/reject orders.
- **Manager dashboard**: Assign orders to drivers, view live driver locations, manage drivers (add/edit/deactivate).
- **Driver app**: See assigned orders, update status, share GPS location, navigate to customers.
- **Fee flexibility**: Manager can choose between **percentage** or **fixed** commission.
- **Free tier**: Works entirely on Firebase’s Spark plan (no paid upgrades).
